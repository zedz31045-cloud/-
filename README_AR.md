# بناء DafanTikTokControl.exe دون تثبيت Python على جهازك

هذه الحزمة تحتوي على المصدر وملف GitHub Actions الذي يبني EXE على خادم Windows مستضاف. لا يمكنني الادعاء أن EXE مبني أو مختبر قبل تشغيل عملية البناء.

## أسهل طريقة للحصول على EXE
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع، بما فيها المجلد `.github/workflows`.
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build Windows EXE** ثم **Run workflow** (أو انتظر البناء بعد push).
5. بعد نجاح المهمة، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
6. نزّل `DafanTikTokControl-Windows.zip` وفك ضغطه. ستجد `DafanTikTokControl.exe`.
7. شغّل EXE على Windows 10/11 من دون تثبيت Python.

## تسجيل الدخول الرسمي
- أنشئ تطبيقاً في https://developers.tiktok.com/
- أضف الصلاحيات المطلوبة في لوحة المطورين.
- استخدم Redirect URI: `http://127.0.0.1:8765/callback` إذا قبله إعداد تطبيقك، وإلا عدّل `REDIRECT_URI` في `app.py` إلى عنوان مسجّل ومعتمد.
- أدخل Client Key وClient Secret داخل التطبيق. لا تشارك السر أو ملف الإعدادات.

## حدود الوظائف
تحتاج معلومات الحساب والفيديوهات إلى موافقة وصلاحيات TikTok. النشر المباشر يحتاج اعتماد Content Posting API. إدارة التعليقات والمتابعين ليست مضمونة عبر واجهات عامة. زر الإبلاغ يفتح صفحة الحساب؛ يجب إكمال البلاغ يدوياً داخل TikTok لأن واجهة المطور العامة لا توفر هنا إرسال بلاغ آلياً.

## تنبيه
ملف EXE لا يعني أن TikTok وافق على التطبيق. هذا المشروع لا يتجاوز الصلاحيات الرسمية ولا يحفظ كلمة مرور TikTok.
