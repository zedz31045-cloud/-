# Dafan TikTok Control — واجهة دفان

واجهة داكنة مرتبة تحمل علامة «دفان»، وتشمل تسجيل الدخول الرسمي، عرض معلومات الحساب والفيديوهات حسب الصلاحيات، وزر إعداد بلاغ داخل البرنامج.

## بناء EXE دون Python على جهازك
1. ارفع كل محتويات المجلد إلى مستودع GitHub جديد.
2. افتح Actions > Build Windows EXE > Run workflow.
3. بعد نجاح البناء، افتح Artifacts ونزّل DafanTikTokControl-Windows.zip.
4. فك الضغط وشغّل DafanTikTokControl.exe. لا تحتاج تثبيت Python على جهاز التشغيل.

## Client Key
ادخل https://developers.tiktok.com/ > Manage apps > اختر التطبيق > App details > Credentials. ستجد Client key وClient secret. أضف المنتجات والصلاحيات المطلوبة، وراجع إعداد Redirect URI في app.py.
لا تضع أسرار التطبيق في مستودع عام. تخزين Client Secret داخل تطبيق سطح مكتب قابل للتوزيع ليس حماية قوية؛ لا توزّع التطبيق على الآخرين بهذه البنية.

## بخصوص البلاغ
الواجهة تتضمن نموذجاً داخل الأداة لتجهيز نص البلاغ ونسخه، لكنها لا ترسله إلى TikTok. لا توفر واجهات TikTok العامة الموثقة هنا نقطة لإرسال بلاغ عن حساب آخر نيابةً عن المستخدم. لذلك لا يمكن جعل زر يرسل بلاغاً حقيقياً من داخل الأداة باستخدام API رسمية. البلاغ الفعلي يجب تقديمه عبر TikTok. لا ينبغي إرسال بلاغات غير صحيحة أو جماعية.

## حدود API
عرض البيانات يعتمد على الموافقات والصلاحيات. هذا المشروع لا يدّعي أنه يوفّر إدارة التعليقات/المتابعين أو نشر الفيديو مباشرة؛ تلك الوظائف ليست مفعّلة بالكامل في هذه النسخة. TikTok قد يقيّد النشر إلى الخاص للتطبيقات غير المدققة.
